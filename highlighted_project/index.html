Highlighted Project: Virtual Rubik's Cube
Creation of an interactive virtual Rubik's cube in Blender, along with a Rubik's Cube solver to find solutions to the Cube given any scramble.

Through the use of A* search with a custon Rubik's Cube heuristic function in C++, I was able to find an efficient solution to a Rubik's Cube given any scramble.

Using Blender's 3D graphics to bring the cube to life and using Python to animate the cube, I was able to visualize the solution and play out the turns needed to replicate the solution.
